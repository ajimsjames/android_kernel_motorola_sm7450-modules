# Motorola SM7450 Kernel Modules

Out-of-tree hardware kernel modules and drivers for Motorola SM7450 platform devices (`tank` / `sm7450-common`).

## Contents

* Motorola sensor, touchscreen, audio, power, and camera kernel modules.
* Qualcomm techpack drivers and vendor module configurations.
